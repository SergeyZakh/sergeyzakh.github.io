01

Berichtsheft

v0.5.0

Der IHK-Ausbildungsnachweis aus dem CSV-Export der Zeiterfassung, als Word oder PDF.

Demo Docs Code Berichtsheft.html

Was es kann

Liest Clockify, Harvest, Jira mit Tempo, Kimai, Toggl Track oder Excel und schreibt Wochenblätter nach IHK-Vordruck.

Wie es läuft

Eine HTML-Datei, auch offline. Auf Wunsch mit Server, Konten und einer Ansicht für Ausbilder.

Gebaut mit

JavaScript ohne Framework, docx, Node, PostgreSQL, OIDC. Getestet mit Playwright.

Fundus

Vorabversion

Firmenwiki mit KI-Suche zum Selbstbetreiben. Die Inhalte verlassen das eigene Netz nicht.

Docs Code

Was es kann

„Frag Fundus“ antwortet nur aus Artikeln, die die fragende Person lesen darf, und nennt die Quellen.

Wie es läuft

Fertiger Docker-Stapel: BookStack, MariaDB, draw.io, Texterkennung, Ollama und nächtliche Sicherung.

Gebaut mit

Theme für BookStack in PHP und JavaScript, Einrichtung in Python, Anmeldung über Keycloak.
